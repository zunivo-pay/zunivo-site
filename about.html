About

Updated October 2026

zunivo is built and run by one person in Toronto, Canada. It started in July 2026 on the Arc testnet and moved to mainnet the day Arc opened, September 16, 2026.

The idea is narrow on purpose: let a program pay for an API call the way a person pays for a coffee, without an account, a card or someone clicking approve. Arc settles in USDC and in about a second, which makes that practical.

What exists today

  • Five contracts on Arc mainnet, source verified, 91 tests. zunivo-contracts
  • An Express middleware and an agent client for x402. zunivo-x402-arc
  • An MCP server so Claude and other MCP clients can pay for things. zunivo-mcp
  • The app at app.zunivo.io for payment links, names, scheduled sends and splits.
  • Three paid endpoints listed on the Circle Agent Marketplace, served from api.zunivo.io.

What doesn't exist yet

  • A company. zunivo is currently operated as an individual project; incorporation is in progress.
  • An independent audit. The contracts have an internal review and a test suite; a third-party audit is planned.
  • A multisig. The contract owner key is a single key for now.

These are listed because you should know them before putting real money through the contracts.
